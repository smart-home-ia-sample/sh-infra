# Smart Home AI — Overview
Public portfolio project for a simulated smart home. Demonstrates LangChain, LangGraph, BFA, A2A, MCP and AG-UI. No real IoT hardware and no relation to legal/contract systems.

MVP commands:
1. Apague as luzes da sala.
2. Estou indo dormir.
3. Vou sair de casa.
4. Como está o consumo de energia?
5. O que está acontecendo na casa?

Definition of done: Docker Compose starts BFA, Orchestrator, Security, Environment, Energy, Home MCP and frontend; agents/MCP self-register; BFA routes; A2A works; MCP exposes tools/resources/prompts; AG-UI shows execution; tests and docs exist.
