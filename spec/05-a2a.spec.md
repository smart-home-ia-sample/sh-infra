# A2A
A2A is used for independent agent collaboration. MVP flows: Orchestrator->Security secure_home; Orchestrator->Environment switch_off_nonessential; Orchestrator->Energy inspect_consumption; Security->Energy identify critical active devices.

Message fields: task_id, sender, recipient, intent, input, correlation_id. Response: task_id, status, result, correlation_id. Require timeout, explicit status, correlation IDs, idempotency and safe retries. Never call another agent's internal functions/classes.
